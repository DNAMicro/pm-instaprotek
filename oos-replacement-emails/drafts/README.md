Review files and the run log for the OOS replacement email skill
(`instaprotek-oos-replacement`).

Each run creates one review file per email here (`YYYY-MM-DD_claim-<claim number>.md`) plus a row
in `_oos_log.csv`. The actual unsent drafts live in the support@instaprotek.com mailbox — these
files are Sarah's review copies, not the delivery mechanism. Nothing here is ever sent
automatically.
